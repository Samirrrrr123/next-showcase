# Витрина

Проект на Next.js по заданию code.mu.

Товары находятся в `data/products.js`. На главной странице показаны карточки, а по нажатию открывается описание товара.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000.

Сборка: `npm run build`. Готовый сайт будет в папке `out`.
